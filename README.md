# duduphudu.app

The source of https://duduphudu.app: Omarchy plugins, apps and tools by DuduPhudu, on one page.

It is plain HTML with no build step. GitHub Pages serves this repository at the domain in `CNAME`, and project pages appear under it, such as PenguID at https://duduphudu.app/omarchy-penguid/.

Plugin preview images come from each plugin's own repository and its Omarchy marketplace listing.
